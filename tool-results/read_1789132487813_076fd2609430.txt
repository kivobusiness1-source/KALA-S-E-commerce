    72→  - POST: Creates a new fund transfer request:
    73→    - Validates affiliate auth via `affiliate_token` cookie
    74→    - Validates amount > 0 and amount <= affiliate.pendingEarnings
    75→    - Validates phoneNumber required for mobile_money, bankInfo required for bank_transfer
    76→    - Creates FundTransferRequest with status `pending`, scheduledAt = now + 2h
    77→    - Moves amount from pendingEarnings to paidEarnings immediately (reserves funds)
    78→    - Updates status to `scheduled` (2h delay is for actual payout execution only)
    79→    - Returns created request with 201 status
