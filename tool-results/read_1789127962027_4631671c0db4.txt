    65→    65→    65→  - GET: Lists fund transfer requests for authenticated affiliate (ordered by createdAt desc)
    66→    66→    66→  - GET with `?action=processScheduled`: Cron endpoint that finds scheduled requests where `scheduledAt <= now()`, processes them by:
    67→    67→    67→    1. Changing status from `scheduled` → `processing` → `completed`
    68→    68→    68→    2. Moving amount from affiliate.pendingEarnings to affiliate.paidEarnings (decrement/increment)
    69→    69→    69→    3. Creating an AffiliatePayout record with status `completed`
    70→    70→    70→    4. Setting processedAt to now()
    71→    71→    71→    5. On failure, marks request as `failed` with error notes
    72→    72→    72→  - POST: Creates a new fund transfer request:
    73→    73→    73→    - Validates affiliate auth via `affiliate_token` cookie
    74→    74→    74→    - Validates amount > 0 and amount <= affiliate.pendingEarnings
    75→    75→    75→    - Validates phoneNumber required for mobile_money, bankInfo required for bank_transfer
    76→    76→    76→    - Creates FundTransferRequest with status `pending`, scheduledAt = now + 2h
    77→    77→    77→    - Moves amount from pendingEarnings to paidEarnings immediately (reserves funds)
    78→    78→    78→    - Updates status to `scheduled` (2h delay is for actual payout execution only)
    79→    79→    79→    - Returns created request with 201 status
